# 日付メモ 完成版 v5

## 固定仕様

- メモ・写真はiPhone内のIndexedDBのみに保存
- バックアップは手動作成、復元も手動選択
- 記録データの外部送信なし
- アプリ本体のみHTTPS配布
- クラウド同期、アカウント、広告、解析、外部API/CDNなし

## 更新耐性

- DB名とデータ形式を固定し、アプリ更新と記録データを分離
- Service Worker更新ではアプリキャッシュだけ交換しIndexedDBは削除しない
- manifestにid/scopeを設定
- 利用可能なら永続ストレージを要求
- バックアップにappVersion/schemaVersionを記録
- 更新確認はアプリ本体だけ。メモ・写真は送信しない

## 注意

OSレベルの端末バックアップや将来のiOS仕様変更そのものはPWAから完全には制御できません。重要な記録は「このiPhone内」へ定期的に手動バックアップしてください。
